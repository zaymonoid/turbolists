    What's in the app today

    Small on purpose.

    No accounts, no cloud, no feed. It does one job and gets out of the way at the trailhead.

    Merge

    Shared items appear once

    Headlamp, knife and first aid kit are in half your kits. On a trip they show up a single time, in the position of the first kit that uses them.

    Order

    Kits keep their order

    Put items in the order you pack them. The merged trip list follows that order kit by kit, so the car loads the same way every time.

    Pack

    Check off with a click

    A progress count at the top, a haptic tap on each check, and a reset so the same trip is ready to pack again next weekend.

    Reuse

    See where a kit is used

    Each kit shows how many trips use it and each item shows which kits it belongs to, so a change never lands somewhere you didn't expect.

    Local

    Your data stays on your phone

    Everything is a plain JSON file on the device. No sign-up, nothing sent anywhere, and it works with no signal at the campsite.

    Fast

    Opens straight to the trip

    Native app built for phones. No spinner, no sync wait, no "what's new" screen between you and the list.
